Core Concepts

KDD, Data Mining & the Pipeline

Data Mining (a.k.a. KDD) = automated discovery of interesting, non-trivial, implicit, previously unknown, potentially useful patterns from large data. It is a step in the broader KDD process.

What Makes a Pattern "Interesting"?

CriterionMeaningMeasure Type
Easily understoodHumans can interpret and act on itSubjective
Valid on new dataGeneralises beyond training setObjective (confidence, support)
Potentially usefulLeads to actionable business insightSubjective (actionability)
NovelNot previously known or obviousSubjective (unexpectedness)
Objective measures: support, confidence, lift. Subjective measures: unexpectedness, actionability — depend on user's prior knowledge.

Data Mining relies on a DBMS (or Data Warehouse) as its data source. They are complementary, not competing technologies.

Association Rules — Key Metrics

Association rules have the form $X \Rightarrow Y$ and are measured by:

MeasureFormulaMeaning
Support$\text{sup}(X \cup Y) = \dfrac{|T_{XY}|}{|T|}$Fraction of all transactions containing both X and Y
Confidence$\text{conf}(X \Rightarrow Y) = \dfrac{\text{sup}(X \cup Y)}{\text{sup}(X)}$Probability Y appears given X appears
Lift$\text{lift}(X \Rightarrow Y) = \dfrac{\text{conf}(X \Rightarrow Y)}{\text{sup}(Y)}$Lift > 1 means positive correlation; filters coincidental co-occurrence
Example: Diapers ⇒ Beer. If sup = 0.3, conf = 0.6 — 30% of all transactions contain both; 60% of diaper purchases also include beer.

03
Mining Tasks

What Kind of Patterns Can Be Mined?

Descriptive

Summarise general properties of the data. No target variable — the goal is to describe what exists.

  • Characterization
  • Discrimination
  • Frequent patterns & association rules
  • Correlation analysis
  • Cluster analysis
Predictive

Use known data to build a model that forecasts unknown or future values of a target attribute.

  • Classification (discrete labels)
  • Regression (continuous values)
  • Outlier / anomaly detection

Mining Tasks — Complete Reference Table

TaskFamilyCore IdeaExample
CharacterizationDescriptiveSummarise features of a target classProfile of top-spending customers: age 25–34, urban, tech-savvy
DiscriminationDescriptiveCompare target class vs contrasting classesFrequent buyers vs rare buyers — what distinguishes them?
Frequent PatternsDescriptiveItemsets, subsequences, substructures that recur beyond a minimum support threshold{Milk, Bread} appears in 40% of transactions
Association RulesDescriptive$X \Rightarrow Y$ judged by support and confidenceDiapers ⇒ Beer [sup=30%, conf=60%]
Correlation AnalysisDescriptiveFilters out coincidental co-occurrence using lift/correlation coefficientRemove rules with lift ≤ 1 (negatively correlated)
ClassificationPredictive (supervised)Model maps objects to predefined discrete labels; trains on labelled dataLoan application → Safe / Risky; Email → Spam / Not-Spam
RegressionPredictivePredicts continuous numerical values from input featuresFuture stock price, house price, temperature forecast
Cluster AnalysisUnsupervisedGroup unlabelled data: maximise intra-class similarity, minimise inter-class similarity; no predefined labelsCustomer segmentation; document clustering
Outlier AnalysisAnomaly DetectionObjects that deviate significantly from the normal model — may be noise or genuinely interestingCredit card fraud detection; network intrusion; medical anomalies

Classification — Model Types

AlgorithmIdeaUse Case
Decision TreeRecursively split data on best attribute; produces human-readable treeLoan approval, medical diagnosis
Naïve BayesProbabilistic; assumes feature independence; uses Bayes' theorem: $P(C|X) \propto P(X|C) \cdot P(C)$Spam filtering, text classification
Neural NetworkLayered weighted nodes; learns non-linear boundariesImage recognition, speech, complex patterns
k-NNClassify by majority vote of k nearest neighboursRecommender systems, anomaly detection
SVMFinds maximum-margin hyperplane separating classesBioinformatics, text categorisation

Cluster Analysis vs Classification

AspectClassificationCluster Analysis
LabelsPredefined class labels (supervised)No labels — discovered by algorithm (unsupervised)
GoalAssign new instance to known classDiscover natural groupings in data
Training dataRequires labelled training setNo training labels needed
OutputClass label for each instanceGroup membership + cluster descriptions
Example algorithmsDecision Tree, Naïve Bayes, SVM, NNk-Means, DBSCAN, Hierarchical clustering
⚠ Exam trap: Outlier analysis is not the same as cluster analysis. Outliers are objects that do not belong to any cluster.

Frequent Pattern Mining — Market Basket Example

TIDItems
T100Bread, Milk, Butter
T200Bread, Diapers, Beer, Eggs
T300Milk, Diapers, Beer, Cola
T400Bread, Milk, Diapers, Beer
T500Bread, Milk, Diapers, Cola
Frequent itemset {Milk, Bread} appears in T100, T400, T500 → $\text{sup} = 3/5 = 60\%$.
Rule: Diapers ⇒ Beer. Diapers in T200,T300,T400,T500. Beer in T200,T300,T400. $\text{conf} = 3/4 = 75\%$.

Machine Learning Paradigms in Data Mining

ParadigmLabelled Data?GoalExample Tasks
Supervised LearningYes — fully labelledLearn mapping from inputs to outputsClassification, Regression
Unsupervised LearningNo labelsDiscover hidden structure in dataClustering, Association rules, Dimensionality reduction
Semi-Supervised LearningFew labelled + many unlabelledUse structure of unlabelled data to improve supervised modelWeb page classification, speech analysis
Active LearningMinimal — model queries for most informative labelsMinimise labelling cost while maximising accuracyMedical image annotation, rare event detection
Key distinction: ML stresses accuracy. Data Mining additionally stresses scalability (terabyte+ datasets), efficiency, and interestingness of discovered patterns.
