Data Cleaning — Missing Values, Noise & Binning

Handling Missing Values — 6 Methods

#MethodWhen to UseDrawback
1Ignore the tupleWhen class label is missing; small datasetPoor if missingness varies by attribute; loses data
2Fill manuallySmall datasets with domain experts availableImpractical for large data; time-consuming
3Global constantQuick placeholder needed (e.g. "Unknown" or −∞)Mining algorithm may treat "Unknown" as interesting
4Attribute mean / medianNumeric attributes; mean for symmetric distributionsMay distort distributions; use median for skewed data

✅ Preferred method: Most probable value (method 6) — uses the data's own structure to infer missing entries via regression or Bayesian inference.

Noisy Data — Sources & Smoothing Techniques

Noise = random error or variance in a measured variable. It corrupts the actual value, making patterns harder to detect.
TechniqueHow It WorksBest For
BinningSort data, place into bins; replace values with bin mean / median / boundaryLocal smoothing; ordered data

VariantRuleResult

Chi-Square Test — Detecting Redundancy in Nominal Data

Used to test if two nominal (categorical) attributes A and B are correlated. A large χ² value → strong correlation → likely redundant.
$$\chi^2 = \sum_{i=1}^{r}\sum_{j=1}^{c}\frac{(o_{ij}-e_{ij})^2}{e_{ij}}, \quad e_{ij} = \frac{\text{count}(A=a_i)\times\text{count}(B=b_j)}{n}$$
SymbolMeaning
$o_{ij}$Observed frequency in cell (i, j)
$e_{ij}$Expected frequency if A and B were independent
$r, c$Number of rows and columns in the contingency table
$n$Total number of tuples
dfDegrees of freedom = $(r-1)(c-1)$

Worked Example — Chess vs Fiction (n = 1500)

FictionNot FictionTotal
Chess250 (exp 90)200 (exp 360)450
Not Chess50 (exp 210)1000 (exp 840)1050
Total30012001500
$e_{11} = \frac{450 \times 300}{1500} = 90$    $e_{12} = \frac{450 \times 1200}{1500} = 360$
$e_{21} = \frac{1050 \times 300}{1500} = 210$    $e_{22} = \frac{1050 \times 1200}{1500} = 840$
$$\chi^2 = \frac{(250-90)^2}{90} + \frac{(50-210)^2}{210} + \frac{(200-360)^2}{360} + \frac{(1000-840)^2}{840} \approx 507.93$$
df = $(2-1)(2-1) = 1$. Critical value at 0.001 level = 10.828.
✅ Since 507.93 > 10.828, we reject independence. Chess-playing and fiction-reading are strongly correlated → one may be redundant if both are in the dataset.
⚠ χ² does NOT imply causality, only correlation. High χ² means redundancy is likely.

Pearson Correlation — Detecting Redundancy in Numeric Data

Used for numeric attributes. Range of $r_{A,B}$ is $[-1, +1]$. Values near ±1 indicate strong correlation (likely redundant).
$$r_{A,B} = \frac{\sum_{i=1}^{n}(a_i-\bar{A})(b_i-\bar{B})}{n\sigma_A\sigma_B} = \frac{\sum a_i b_i - n\bar{A}\bar{B}}{n\sigma_A\sigma_B}$$ $$\text{Cov}(A,B) = \frac{\sum_{i=1}^{n}(a_i-\bar{A})(b_i-\bar{B})}{n}$$
$r_{A,B}$ valueInterpretation
$r = +1$Perfect positive correlation — A increases, B increases proportionally
$0 < r < 1$Positive correlation — may be redundant
$r = 0$No linear correlation — independent
$-1 < r < 0$Negative correlation — inversely related
$r = -1$Perfect negative correlation

Worked Example — Covariance

A = (6, 5, 4, 3, 2), B = (20, 10, 14, 5, 5)    $\bar{A} = 4$, $\bar{B} = 10.8$, $n = 5$
$$\text{Cov}(A,B) = \frac{\sum a_i b_i}{n} - \bar{A}\cdot\bar{B} = \frac{6(20)+5(10)+4(14)+3(5)+2(5)}{5} - 4 \times 10.8$$
$= \frac{120+50+56+15+10}{5} - 43.2 = \frac{251}{5} - 43.2 = 50.2 - 43.2 = \mathbf{7}$
Positive covariance (Cov = 7 > 0) confirms A and B are positively correlated.

Reduction

Data Reduction — Smaller Representation, Same Insight

Goal: Obtain a reduced representation of the dataset that is much smaller in volume, yet produces the same (or nearly the same) analytical results as the original.

Reduction Techniques Overview

TechniqueTypeKey IdeaNotes
Wavelet Transform (DWT) Non-parametric, lossy Linear transform of vector X into equal-length coefficient vector X'. Keep strongest coefficients, zero the rest. O(n) time. Better than DFT: spatial localization. Families: Haar-2, Daubechies-4. Suits sparse data & images.
PCA (Karhunen-Loève) Parametric, lossy Find $k \le n$ orthogonal principal components sorted by decreasing variance; drop weak components. Normalize first. Numeric data only. New axes (PCs) are hard to interpret but capture max variance.
Attribute Subset Selection Non-parametric Remove irrelevant, weak-predictor, and redundant attributes. Reduces dimensionality without transformation. Preserves original attributes. Multiple heuristic methods (see below).
Regression Parametric, lossy Fit $y = wx + b$ by least squares. Store only model parameters $(w, b)$ instead of all data points. Works for linear relationships. Multiple linear regression extends to multiple predictors.
Log-linear Models Parametric, lossy Approximate discrete multi-dimensional distributions with lower-dimensional ones. Useful for sparse high-dimensional categorical data.
Histograms Non-parametric Partition attribute values into disjoint buckets; store (bucket_range, count) pairs instead of raw data. Equal-width or equal-frequency buckets. Very compact summary of numeric distributions.

Attribute Subset Selection — Heuristic Methods

MethodStart WithStrategy
Stepwise Forward SelectionEmpty set {}At each step, add the attribute that most improves the model; stop when no improvement
Stepwise Backward EliminationFull attribute setAt each step, remove the worst (least useful) attribute; stop when removal hurts model
Combined Forward + BackwardArbitraryAlternate between adding best and removing worst attributes each iteration
Decision Tree InductionFull setBuild a decision tree; attributes appearing at non-leaf nodes form the selected subset
Exam tip: PCA creates new axes (principal components). Attribute subset selection keeps original attributes. PCA is lossy and transformative; selection is a filter.

DWT vs PCA — Quick Comparison

AspectDWT (Wavelet)PCA

Transformation & Discretization

Transformation Strategies

StrategyDescription
SmoothingRemove noise from data (binning, regression)
Attribute constructionDerive new attributes from existing ones (e.g. BMI from height & weight)
AggregationSummarize data (daily sales → monthly totals)
NormalizationScale attribute values to a small range (critical for distance-based methods)
DiscretizationConvert continuous values to interval/ordinal labels (binning)

Normalization Methods

Why normalize? Prevents large-range attributes (e.g. income: 0–100,000) from dominating small-range ones (e.g. age: 0–100) in distance-based methods like K-Means and KNN.
MethodFormulaOutput RangeBest For
Min-Max $v' = \dfrac{v - \min_A}{\max_A - \min_A}(\text{new\_max} - \text{new\_min}) + \text{new\_min}$ [new_min, new_max] Known min/max; preserves relationships; common [0,1]
Z-Score $v' = \dfrac{v - \bar{A}}{\sigma_A}$  (or use MAD for outlier robustness) Approx. [−3, +3] Unknown min/max; outliers present; Gaussian-like distributions
Decimal Scaling $v' = \dfrac{v}{10^j}$  where $j$ = smallest integer with $\max(|v'|) < 1$ $(−1, +1)$ Quick scaling; integer-friendly; magnitude-based

Normalization Worked Example

Attribute: Income  |  $\min = 12{,}000$  |  $\max = 98{,}000$  |  $\bar{A} = 54{,}000$  |  $\sigma = 16{,}000$  |  $v = 73{,}600$
Min-Max to [0, 1]: $$v' = \frac{73600 - 12000}{98000 - 12000} = \frac{61600}{86000} \approx 0.716$$
Z-Score: $$v' = \frac{73600 - 54000}{16000} = \frac{19600}{16000} = 1.225$$
Decimal Scaling: If $\max|v| = 986$, then $j = 3$ (since $\frac{986}{10^3} = 0.986 < 1$). So every value is divided by 1000.
MethodAdvantageLimitation
Min-MaxPreserves original relationships; bounded outputFails for new values outside [min, max] (clipping needed)
Z-ScoreHandles outliers better; works without known boundsOutput range is unbounded; not intuitive
Decimal ScalingSimple, integer-friendlyDepends on magnitude of data; loses relative spacing

Discretization by Binning (Unsupervised)

MethodRuleFormulaCharacteristic
Equal-WidthAll bins have the same interval size $w$$w = \dfrac{\max - \min}{k}$Simple; outlier-sensitive (creates very uneven population bins)
Equal-Frequency (Equal-Depth)All bins contain the same number of valuesSort, then split into $k$ groups of size $\lfloor n/k \rfloor$Balanced bins; better for skewed data
