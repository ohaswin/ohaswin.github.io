Foundations

Association Rule Mining — Concepts & Itemsets

Association Rule: Implication of the form $X \Rightarrow Y$, where $X, Y \subset I$ and $X \cap Y = \emptyset$. $X$ is antecedent, $Y$ is consequent. Discovers co-occurrence relations like $\{\text{Diapers}\} \Rightarrow \{\text{Beer}\}$.

Core Terminology

TermMeaning & Formula
ItemsetA set of items. A $k$-itemset contains $k$ distinct items.
Support Count ($\sigma$)Absolute frequency of an itemset in dataset $D$: $\sigma(X) = |\{t \in D \mid X \subseteq t\}|$
SupportFraction of total transactions containing $X \cup Y$: $$\text{Support}(X \Rightarrow Y) = P(X \cup Y) = \frac{\text{count}(X \cup Y)}{|D|}$$
ConfidenceConditional certainty of $Y$ given $X$: $$\text{Confidence}(X \Rightarrow Y) = P(Y \mid X) = \frac{\text{count}(X \cup Y)}{\text{count}(X)}$$
Strong RuleA rule that satisfies both $\text{min\_sup}$ and $\text{min\_conf}$ thresholds.
Subsequence / SubstructureOrdered pattern (e.g. $A \to B$) or subgraph / subtree in structured graphs.

Closed vs Maximal Frequent Itemsets

FeatureClosed Frequent ItemsetMaximal Frequent Itemset
DefinitionFrequent itemset where no proper superset has the same support count.Frequent itemset where no proper superset is frequent.
Compression TypeLossless: Supports of all subsets can be fully derived.Maximal / Lossy: More compact, but exact subset supports are lost.
RelationshipEvery maximal frequent itemset is closed ($\text{Maximal} \subseteq \text{Closed} \subseteq \text{Frequent}$).A strict subset of closed itemsets are maximal.
Worked Example: $D = \{T_1:\{A,B,C\}, T_2:\{A,B,C\}, T_3:\{A,B\}, T_4:\{A,D\}\}$, $\text{min\_sup}=2$.
Supports: $A:4, B:3, C:2, AB:3, AC:2, BC:2, ABC:2$ ($D, AD$ infrequent).
• Closed: $\{A\}:4$, $\{A,B\}:3$, $\{A,B,C\}:2$
• Maximal: $\{A,B,C\}:2$ only (its proper supersets are not frequent).
02
Frequent Patterns

Apriori Algorithm & Level-Wise Pruning

Apriori Property (Anti-monotonicity): Any non-empty subset of a frequent itemset must also be frequent. If an itemset $I$ is infrequent, all of its supersets are immediately pruned without scanning the database!

Level-Wise Candidate Generation & Pruning

  1. Find $L_1$: Scan $D$ to count 1-itemsets; retain itemsets with count $\ge \text{min\_sup}$.
  2. Join Step ($C_k$): Join $L_{k-1}$ with itself ($L_{k-1} \Join L_{k-1}$) on matching prefix of length $k-2$.
  3. Prune Step: Discard candidate $c \in C_k$ if any $(k-1)$-subset of $c$ is not in $L_{k-1}$.
  4. Count & Select ($L_k$): Scan database $D$ to compute support of surviving candidates. Keep those $\ge \text{min\_sup}$. Repeat until $C_k = \emptyset$.

Worked Example: Full Run

$D = \{T_1:\{A,B,C\}, T_2:\{A,C\}, T_3:\{A,D\}, T_4:\{B,E\}\}$, $\text{min\_sup} = 2$.

IterationCandidate Set ($C_k$)CountsFrequent Itemset ($L_k$)
k=1$\{A\}, \{B\}, \{C\}, \{D\}, \{E\}$$A:3, B:2, C:2, D:1, E:1$$L_1 = \{\{A\}, \{B\}, \{C\}\}$
k=2$\{AB\}, \{AC\}, \{BC\}$$AB:1, AC:2, BC:1$$L_2 = \{\{A, C\}\}$
k=3No 3-candidates constructible from $L_2$—Stop
Bottlenecks & Enhancements: Apriori needs $k$ database scans and generates huge candidate sets. Optimizations include: Hash-based item filtering (PCY), Transaction reduction, Partitioning, and Sampling.
03
Rule Extraction

Generating Strong Rules from Frequent Itemsets

Confidence Calculation & Anti-Monotonicity

For each frequent itemset $l \in L_k$, generate all non-empty proper subsets $s \subset l$. Candidate rule $s \Rightarrow (l - s)$ is valid if:

$$\text{Confidence}(s \Rightarrow l - s) = \frac{\text{Support}(l)}{\text{Support}(s)} \ge \text{min\_conf}$$
Pruning Property: If $s \Rightarrow (l - s)$ fails $\text{min\_conf}$, then any $s' \Rightarrow (l - s')$ with $s' \subset s$ also fails confidence and is pruned immediately.

Worked Example: Rules from $\{B, C, E\}$

Given frequent itemset $L = \{B,C,E\}$, $\sigma(BCE)=2, \sigma(BC)=2, \sigma(CE)=2, \sigma(BE)=3, \sigma(B)=3, \sigma(C)=3, \sigma(E)=3$. $\text{min\_conf} = 70\%$.

$C \wedge E \Rightarrow B$$\sigma(BCE) / \sigma(CE) = 2/2$100%Strong Rule
$B \wedge E \Rightarrow C$$\sigma(BCE) / \sigma(BE) = 2/3$66.7%Pruned
$B \Rightarrow C \wedge E$$\sigma(BCE) / \sigma(B) = 2/3$66.7%Pruned

Splitting Criteria

Information Gain, Gain Ratio & Gini Index

Attribute Selection Comparison

MeasureOrigin AlgorithmKey Characteristics & BiasSplitting Formula
Information GainID3Biased towards multi-valued attributes (e.g. ID numbers).$\text{Gain}(A) = \text{Info}(D) - \text{Info}_A(D)$
Gain RatioC4.5Normalizes by SplitInfo to penalize fragmented splits.$\text{GainRatio}(A) = \frac{\text{Gain}(A)}{\text{SplitInfo}_A(D)}$
Gini IndexCARTEnforces strictly binary splits; measures dataset impurity.$\Delta\text{Gini}(A) = \text{Gini}(D) - \text{Gini}_A(D)$

Mathematical Formulations

$$\text{Info}(D) = -\sum_{i=1}^{m} p_i \log_2(p_i), \quad \text{Info}_A(D) = \sum_{j=1}^{v} \frac{|D_j|}{|D|} \text{Info}(D_j)$$
$$\text{SplitInfo}_A(D) = -\sum_{j=1}^{v} \frac{|D_j|}{|D|} \log_2\left(\frac{|D_j|}{|D|}\right)$$
$$\text{Gini}(D) = 1 - \sum_{i=1}^{m} p_i^2, \quad \text{Gini}_A(D) = \frac{|D_1|}{|D|} \text{Gini}(D_1) + \frac{|D_2|}{|D|} \text{Gini}(D_2)$$
Worked Example (AllElectronics 14 tuples: 9 yes, 5 no):
$$\text{Info}(D) = -\frac{9}{14}\log_2\frac{9}{14} - \frac{5}{14}\log_2\frac{5}{14} = 0.940$$ Splitting on Age: $\text{Info}_{\text{age}}(D) = \frac{5}{14}(0.971) + \frac{4}{14}(0) + \frac{5}{14}(0.971) = 0.694$
$$\text{Gain}(\text{Age}) = 0.940 - 0.694 = \mathbf{0.246} \quad (\text{highest gain among all features } \to \text{Age selected as Root}).$$
06
Probabilistic Models

Bayes Theorem & Naive Bayes Classifier

Bayes Theorem

$$P(C_i \mid X) = \frac{P(X \mid C_i) \cdot P(C_i)}{P(X)}$$
$P(C_i)$: Prior probability of class $C_i$
$P(X \mid C_i)$: Likelihood of seeing $X$ given $C_i$
$P(X)$: Evidence constant (equal for all classes)
$P(C_i \mid X)$: Posterior probability

Naive Bayes Conditional Independence

Assumes all attributes $x_1, \dots, x_n$ are conditionally independent given class $C_i$:

$$P(X \mid C_i) = \prod_{k=1}^{n} P(x_k \mid C_i) = P(x_1 \mid C_i) \times P(x_2 \mid C_i) \times \dots \times P(x_n \mid C_i)$$
Zero Probability & Laplace Correction: If an attribute value never appears with a class ($P(x_k \mid C_i) = 0$), the product becomes zero! To prevent this, add 1 to each count: $$P(x_k \mid C_i) = \frac{\text{count}(x_k, C_i) + 1}{\text{count}(C_i) + q}$$ where $q$ is the number of distinct values of attribute $k$.

AdaBoost Formulation

$$\text{error}(M_i) = \sum_j w_j \cdot I(M_i(x_j) \ne y_j), \quad \alpha_i = \frac{1}{2}\ln\left(\frac{1 - \text{error}(M_i)}{\text{error}(M_i)}\right)$$

Misclassified instances have their weights boosted by $\exp(\alpha_i)$, while correct instances are downweighted by $\exp(-\alpha_i)$, forcing later models to concentrate on difficult cases.

Model Assessment

Classifier Evaluation & Validation Protocols

Confusion Matrix (2x2)

Actual \ PredictedPredicted PositivePredicted Negative
Actual PositiveTP (True Positive)FN (False Negative - Type II)
Actual NegativeFP (False Positive - Type I)TN (True Negative)

Evaluation Formulas

$$\text{Accuracy} = \frac{TP + TN}{P + N}$$
$$\text{Precision} = \frac{TP}{TP + FP}$$
$$\text{Recall} = \frac{TP}{TP + FN}$$
$$\text{Specificity} = \frac{TN}{TN + FP}$$
$$F_1\text{-score} = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2 \cdot TP}{2 \cdot TP + FP + FN}$$
Class Imbalance Warning: On imbalanced data (e.g. 99% normal, 1% fraud), a dummy classifier predicting 'Normal' achieves 99% accuracy but 0% recall. Always report Precision, Recall, and F1-score!
